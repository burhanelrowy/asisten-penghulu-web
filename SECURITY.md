# Security Policy

## Ruang Lingkup

Asisten Penghulu Web v5.0 merupakan aplikasi static website. Repository ini tidak menyertakan backend, autentikasi pengguna, atau database server.

## Pelaporan Kerentanan

Jika menemukan kerentanan yang berpotensi berdampak pada pengguna, jangan mempublikasikan detail eksploitasi sebelum pemilik repository memiliki kesempatan untuk meninjau dan menangani laporan.

Gunakan fitur **Private vulnerability reporting** pada tab **Security** jika fitur tersebut telah diaktifkan oleh pemilik repository. Jika belum tersedia, hubungi pemilik repository melalui kanal kontak yang tercantum pada profil GitHub.

Jangan menyertakan data pribadi, dokumen pernikahan, atau informasi sensitif dalam issue publik.

## Praktik Keamanan

- Jangan commit password, API key, token, atau kredensial.
- Jangan mengunggah dokumen identitas atau data pribadi.
- Periksa sumber dan integritas file eksternal sebelum menambahkannya.
- Tinjau kembali perubahan pada Service Worker dan cache.
- Ingat bahwa data lokal browser dapat diakses oleh pengguna perangkat yang sama.

## Batasan

Kebijakan ini tidak menjamin bahwa aplikasi telah menjalani audit keamanan independen. Penggunaan dalam lingkungan pelayanan harus didahului penilaian keamanan dan tata kelola data yang sesuai.
